# Roby's adventure

## О проекте
**Roby's adventure** — это 2D-платформер с элементами физического взаимодействия, разработанный в рамках дисциплины ОПД. Проект представляет собой интерактивный опыт, где игроку предстоит преодолевать препятствия, избегать врагов и использовать физические объекты окружения для достижения цели.

## Технологический стек
* **Движок:** Godot Engine 4.x
* **Язык программирования:** GDScript
* **Система контроля версий:** Git (GitHub)
* **Операционная система разработки:** Ubuntu Linux 24.04 LTS (на базе VirtualBox)
* **Автоматизация:** GitHub Actions (CI/CD для сборки релизов)

## Ключевые особенности
* **Физика игрока:** Реализован отзывчивый двойной прыжок через переработанную логику `_integrate_forces` (`RigidBody2D`).
* **Интерактивное окружение:** Система батутов на базе `Area2D` с передачей импульса игроку.
* **Искусственный интеллект:** Враги с логикой патрулирования, использующие `RayCast2D`.
* **CI/CD:** Автоматизированная сборка проекта под целевые платформы при каждом обновлении основной ветки.

## Установка и запуск
1. Клонируйте репозиторий: `git clone https://github.com/ВАШ_НИК/ResidentHorrorX.git`
2. Откройте проект в **Godot Engine 4.x**.
3. Нажмите кнопку "Play" в редакторе для запуска уровня.

## CI/CD
Проект автоматически собирается при помощи GitHub Actions.
